## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 速冻饺子 | 12-15只（约300g） |
| 调和油 | 喷油壶计量 |
| 清水 | 小半碗（100-120ml） |
| 香醋 | 1汤匙（15ml，蘸食可选） |
| 生抽 | ½汤匙（7ml，蘸食可选） |
| 辣椒油 | 适量（蘸食可选） |
| 熟白芝麻 | 少许（可选） |
| 葱花 | 少许（可选） |

## 准备工作

### 1. 检查饺子

从冰箱取出速冻饺子，**无需解冻**。轻轻分开粘连的饺子，拣出已经开裂或严重破损的，避免煎制时漏馅。

### 2. 准备锅具

选用带盖的 **不粘平底锅**，锅底以能平放全部饺子、饺子之间略有空隙为宜。提前准备好锅盖和100-120ml清水。

### 3. 调制蘸汁

取一个小碟，加入香醋1汤匙、生抽½汤匙，再按口味加入少许辣椒油，搅拌均匀备用。

---

## 烹饪步骤

### 步骤一：摆饺喷油

1. 平底锅置于灶上，**中火加热30秒**。
2. 喷油壶对准锅底均匀喷洒 **8-10次**，使锅底覆盖一层薄油。
3. 将速冻饺子直接放入锅中，底部朝下，**饺子之间留出约0.5-1cm空隙**，不要堆叠。

### 步骤二：煎定底壳

保持 **中小火**，煎制 **1-2分钟**。夹起一只饺子观察，底部呈 **浅金黄色** 即可进入下一步。

### 步骤三：加水焖熟

1. 转 **小火**，将100-120ml清水沿锅边缓慢倒入，水量以 **没过饺子底部约三分之一** 为宜。
2. 立即盖上锅盖，转 **中火**，焖煮 **6-8分钟**。
3. 焖煮期间不要频繁开盖，可轻轻晃动锅身1-2次，防止局部粘锅。

### 步骤四：收水煎脆

1. 当锅中水分基本收干、发出轻微的“滋滋”声时，打开锅盖。
2. 沿锅边补喷 **2-3次** 油，转 **中小火**。
3. 继续煎 **2-3分钟**，其间轻轻晃动锅身，直至底部呈均匀金黄色、能轻松脱离锅底。
4. 若饺子已经熟透但底部仍不够脆，可再开盖煎 **1分钟**；注意不要煎糊。

### 步骤五：出锅装盘

关火后用锅铲将饺子逐一铲起，**底部朝上** 放入盘中，保持酥脆。撒上少许熟白芝麻或葱花，搭配蘸汁食用。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 饺子外皮熟了、内馅仍凉 | 焖煮时间不足或火太大，补加2-3汤匙热水，加盖再焖2-3分钟 |
| 水干了但饺子还没熟 | 立即补加少量热水继续焖，不要直接干煎，否则容易外糊内生 |
| 底部容易焦 | 初次只煎至浅金黄，加水后保持中火，收水阶段改为中小火并及时观察 |
| 饺子粘锅、破皮 | 使用不粘锅并喷足薄油，煎脆后再用锅铲轻推，不要过早强行翻动 |
| 饺子相互粘连 | 下锅时留出空隙；若轻微粘连，出锅前用锅铲沿缝隙轻轻分开 |
| 想做冰花脆底 | 清水中加入1茶匙淀粉并搅匀，按同样方法焖煮，收水后形成薄脆冰花 |
| 控油需求 | 初次喷油减少至6-8次，步骤四可不补油，用不粘锅开盖收脆即可 |
