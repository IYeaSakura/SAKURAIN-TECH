## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 茶干 | 2袋（约270g） |
| 青圆椒 | 2个（约300g） |
| 大蒜 | 4-5瓣（约20g） |
| 生姜 | 3片（约10g，可选） |
| 生抽 | 1汤匙（15ml） |
| 蚝油 | ½汤匙（7ml） |
| 老抽 | ¼茶匙（1.5ml，上色用） |
| 白糖 | ½茶匙（3g） |
| 盐 | ¼茶匙（1.5g，可选，视茶干咸度） |
| 鸡精 | ¼茶匙（1g，可选） |
| 香油 | 几滴（可选） |
| 调和油 | 喷油壶计量 |
| 清水 | 3汤匙（45ml） |

## 准备工作

### 1. 处理茶干

茶干拆袋后用温水冲洗表面，切成 **0.5cm 左右的粗条**（比切片更耐炒、不易碎）。如果口味偏淡或对咸度敏感，可用温水浸泡 5 分钟去一部分咸味，捞出后用厨房纸吸干水分备用。

### 2. 处理青圆椒

青圆椒去蒂、对半剖开去籽，切成粗条或滚刀块（圆椒肉厚，切粗一点口感更脆）。洗净后放入沥水篮充分沥干水分。

### 3. 调制碗汁

取一个小碗，按顺序加入：

- 生抽 1汤匙
- 蚝油 ½汤匙
- 老抽 ¼茶匙
- 白糖 ½茶匙
- 盐 ¼茶匙（尝过茶干后决定放不放）
- 鸡精 ¼茶匙
- 清水 3汤匙

搅拌均匀，备用。

## 烹饪步骤

### 步骤一：煎香茶干

1. 炒锅置于灶上，**中大火加热 30 秒**。喷油壶对准锅底均匀喷洒 **8-10 次**，油热后下入姜丝和三分之二蒜末，快速翻炒 **10 秒** 爆出香味。
2. 下入茶干条，转 **中小火**，煎炒 **1-2 分钟**，时不时用锅铲推一推，直到茶干边缘微微焦黄、表面略干。

### 步骤二：大火炒椒

1. 转 **大火**，倒入青圆椒，快速翻炒 **1-1.5 分钟**，至椒皮起皱、断生但仍保持脆嫩。
2. 沿锅边淋入调好的碗汁，继续大火翻炒 **30 秒**，让味道均匀包裹住茶干和青椒。

### 步骤三：出锅装盘

撒入剩余的三分之一蒜末，淋几滴香油，翻炒 **5 秒** 后立即关火。盛入盘中，将茶干和青椒交替码放，浇上锅中少许汤汁即可。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 成品太咸 | 茶干先温水浸泡 5 分钟或入沸水焯 30 秒再炒； 碗汁中的盐直接省略 |
| 青椒出水、不脆 | 洗净后务必沥干，全程大火快炒，不加盖焖煮 |
| 茶干炒碎 | 切条别切片；煎茶干用中小火，用锅铲"推"代替大力翻拌 |
| 颜色寡淡 | 老抽别省，出锅前沿锅边淋几滴香醋还能增香提味 |
| 想升级成荤菜 | 加 100g 五花肉片，先小火煸出油再下茶干，风味立刻上一个台阶 |
| 控油需求 | 喷油减至 6 次，碗汁中清水增至 4 汤匙防止粘锅 |
