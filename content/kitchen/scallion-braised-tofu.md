## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 北豆腐 | 400g |
| 大葱 | 2根（约150g） |
| 生抽 | 2汤匙（30ml） |
| 料酒 | 1汤匙（15ml） |
| 米醋 | ½汤匙（7ml） |
| 白糖 | 1茶匙（5g） |
| 盐 | ½茶匙（3g） |
| 鸡精 | ¼茶匙（1g） |
| 白胡椒粉 | 少许 |
| 调和油 | 喷油壶计量 |
| 清水 | 小半碗（80ml） |

---

## 准备工作

### 1. 处理豆腐

将豆腐切成约 **2cm × 3cm × 1.5cm** 的长方块，或切成三角块。用厨房纸巾轻轻按压吸干表面水分，静置 5 分钟备用。

### 2. 切配大葱

大葱洗净，斜切成 **3-4cm 的葱段**。葱白和葱绿分开放置。

### 3. 调制酱汁

取一个小碗，按顺序加入：

- 生抽 2汤匙
- 料酒 1汤匙
- 米醋 ½汤匙
- 白糖 1茶匙
- 盐 ½茶匙
- 鸡精 ¼茶匙
- 白胡椒粉 少许
- 清水 小半碗

搅拌均匀，备用。

---

## 烹饪步骤

### 步骤一：热锅

平底锅置于灶上，**中火加热 30 秒**。喷油壶对准锅底均匀喷洒 **8-10 次**，使锅底覆盖一层薄油。

### 步骤二：煎豆腐

1. 将处理好的豆腐块逐一放入锅中，**块与块之间留出约 1cm 空隙**，不要堆叠。
2. 转 **中小火**，煎制 **3-4 分钟**。
3. 观察豆腐底部边缘呈金黄色时，用锅铲轻轻翻面。
4. 翻面后，沿锅边补喷 **5-8 次** 油，继续煎 **3 分钟**，至两面均呈均匀金黄色。
5. 将煎好的豆腐盛出，放在厨房纸巾上吸去多余油分。

### 步骤三：炒葱

1. 锅中留底油（若底油不足，补喷 **3-5 次**）。
2. **大火**烧热，先下入葱白段，快速翻炒 **15 秒** 至微微变软。
3. 再下入葱绿段，继续翻炒 **10 秒**，炒出浓郁葱香。

### 步骤四：合炒收汁

1. 将煎好的豆腐倒回锅中，用锅铲**轻轻推动**，使豆腐与葱段混合均匀。
2. 淋入事先调好的酱汁，转 **中火**。
3. 轻轻晃动锅身，让酱汁均匀包裹每一块豆腐，焖煮 **1-2 分钟**。
4. 观察汤汁逐渐浓稠、能挂在豆腐表面时，即可关火。

### 步骤五：出锅装盘

将葱烧豆腐盛入深盘中，把剩余的酱汁浇在表面。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 豆腐容易碎 | 选用北豆腐（老豆腐），切好后静置沥水，煎时不要急着翻面 |
| 不够入味 | 煎好后可用锅铲在豆腐表面轻轻划几刀，或在步骤四中多焖 1 分钟 |
| 想要更浓郁 | 可在酱汁中加入 ½ 茶匙蚝油，或减少清水用量 |
| 控油需求 | 煎好后用厨房纸充分吸油，炒葱时喷油次数可减少至 3-5 次 |
