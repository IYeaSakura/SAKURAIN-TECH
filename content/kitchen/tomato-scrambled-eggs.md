## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 西红柿 | 2个（约400g） |
| 鸡蛋 | 4个（约200g） |
| 小葱 | 1根（约10g，可选） |
| 生抽 | ½汤匙（7ml） |
| 白糖 | 1茶匙（5g） |
| 盐 | ¾茶匙（4g） |
| 料酒 | ½汤匙（7ml，可选） |
| 白胡椒粉 | 少许 |
| 调和油 | 喷油壶计量 |
| 清水 | 2汤匙（30ml，可选） |

---

## 准备工作

### 1. 处理西红柿

西红柿洗净，在顶部划一个浅十字口，放入热水中浸泡 **1分钟**，撕去外皮。切成约 **3cm大小的滚刀块**，将较软的果肉与较硬的果蒂部分分开，去除硬蒂。

### 2. 打散鸡蛋

鸡蛋打入碗中，加入：

- 料酒 ½汤匙
- 盐 ¼茶匙
- 白胡椒粉 少许
- 清水 1汤匙

用筷子充分搅打至蛋液均匀、表面出现细小泡沫，备用。

### 3. 切配小葱

小葱洗净，葱白与葱绿分开，切成葱花备用。不喜欢葱香味可省略。

---

## 烹饪步骤

### 步骤一：热锅

炒锅置于灶上，**中火加热30秒**。喷油壶对准锅底均匀喷洒 **8-10次**，使锅底覆盖一层薄油。

### 步骤二：炒鸡蛋

1. 倒入蛋液，待底部开始凝固、边缘微微鼓起时，用锅铲从外向内轻轻推动。
2. 转 **中小火**，将未凝固的蛋液引向锅底，反复轻推 **1-2分钟**。
3. 鸡蛋炒至 **七八成熟、仍略带湿润** 时，立即盛出备用。

### 步骤三：炒西红柿

1. 锅中补喷 **4-6次** 油，转 **中大火**。
2. 放入葱白，翻炒 **10秒** 出香味。
3. 倒入西红柿块，加入白糖 1茶匙、盐 ½茶匙，翻炒 **2-3分钟**。
4. 用锅铲轻压部分西红柿，使其出汁；若汤汁过少，可沿锅边加入清水 1-2汤匙。
5. 加入生抽 ½汤匙，继续煮至西红柿软烂、汤汁略微浓稠。

### 步骤四：合炒入味

1. 将炒好的鸡蛋倒回锅中，用锅铲轻轻翻拌，使鸡蛋均匀裹上西红柿汁。
2. 保持 **中火**，翻炒 **30秒-1分钟**，让鸡蛋吸收味道。
3. 尝一下汤汁，根据个人口味补少许盐或糖，即可关火。

### 步骤五：出锅装盘

将西红柿炒鸡蛋盛入盘中，撒上葱绿葱花。保留适量汤汁，用来拌米饭风味更佳。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 鸡蛋发老、不嫩 | 蛋液中加1汤匙清水，炒至七八成熟先盛出，回锅后不要久炒 |
| 西红柿不出汁 | 选用熟透的西红柿，炒制时轻压果肉，少量加水帮助出汁 |
| 味道过酸 | 增加½-1茶匙白糖，或延长炒制时间，让酸味变得柔和 |
| 鸡蛋碎得太散 | 炒蛋时等底部定型再推动，回锅后轻翻几下即可 |
| 喜欢汤汁拌饭 | 保留半碗左右的汤汁，不要将汁收得过干 |
| 控油需求 | 使用不粘锅，炒鸡蛋喷油6-8次、炒西红柿喷油3-4次即可 |
