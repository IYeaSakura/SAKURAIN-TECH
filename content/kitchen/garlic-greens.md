## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 青菜（上海青/小油菜） | 400g |
| 大蒜 | 5-6瓣（约25g） |
| 生抽 | 1汤匙（15ml） |
| 蚝油 | ½汤匙（7ml） |
| 盐 | ½茶匙（3g） |
| 白糖 | ¼茶匙（1g） |
| 鸡精 | ¼茶匙（1g，可选） |
| 调和油 | 喷油壶计量 |
| 清水 | 2汤匙（30ml） |

---

## 准备工作

### 1. 处理青菜

将青菜逐片掰开洗净，重点冲洗菜根处的泥沙。较大的青菜可对半切开，小棵的整棵保留即可。洗好后放入沥水篮，**充分沥干水分**，静置 5 分钟备用。

### 2. 处理大蒜

大蒜去皮，用刀背拍松后切成蒜末，分成两份：**三分之二用于爆锅，三分之一出锅前加入**，蒜香更有层次。

### 3. 调制碗汁

取一个小碗，按顺序加入：

- 生抽 1汤匙
- 蚝油 ½汤匙
- 盐 ½茶匙
- 白糖 ¼茶匙
- 鸡精 ¼茶匙
- 清水 2汤匙

搅拌均匀，备用。

---

## 烹饪步骤

### 步骤一：热锅爆香

炒锅置于灶上，**中大火加热 30 秒**。喷油壶对准锅底均匀喷洒 **6-8 次**，油热后下入三分之二的蒜末，快速翻炒 **10-15 秒**，炒出蒜香、蒜末微微发黄即可。

### 步骤二：大火快炒

1. 转 **大火**，立即倒入沥干的青菜，快速翻炒 **30 秒**，让每片菜叶都裹上油。
2. 持续翻炒 **1-2 分钟**，至菜叶变软、菜梗仍保持脆嫩、颜色翠绿油亮。
3. 沿锅边淋入调好的碗汁，继续大火翻炒 **20-30 秒**，让味道均匀附着。

### 步骤三：出锅装盘

撒入剩余的三分之一蒜末，翻炒 **5 秒** 后立即关火。将青菜盛入盘中，菜梗朝内、菜叶朝外码放，浇上锅中少许汤汁即可。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 青菜出水多、不脆 | 洗后务必沥干水分，全程大火快炒，不要加盖焖煮 |
| 颜色发黄 | 炒制时间过长，青菜断生即可出锅；也可先焯水 15 秒再快炒 30 秒 |
| 蒜香不足 | 蒜末分两次加入，出锅前的那份生蒜末是提香关键 |
| 菜梗硬、菜叶烂 | 先下菜梗翻炒 20 秒，再下菜叶同炒 |
| 控油需求 | 喷油可减少至 4-5 次，碗汁中清水增至 3 汤匙防止粘锅 |
