## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 干豆腐 | 300g |
| 青圆椒 | 2个（约200g） |
| 大蒜 | 3瓣 |
| 生抽 | 1½汤匙（22ml） |
| 蚝油 | 1汤匙（15ml） |
| 料酒 | 1汤匙（15ml） |
| 白糖 | ½茶匙（3g） |
| 盐 | ¼茶匙（1.5g） |
| 鸡精 | ¼茶匙（1g） |
| 水淀粉 | 2汤匙（淀粉1茶匙+清水15ml） |
| 调和油 | 喷油壶计量 |
| 清水 | 一碗（用于焯水） |

## 准备工作

### 1. 处理干豆腐

将干豆腐切成约 **3cm × 4cm 的菱形块**（或宽条）。烧一锅开水，水开后放入干豆腐，加 **¼ 茶匙盐**，焯烫 **1 分钟**，捞出过凉水，沥干水分备用。

### 2. 切配青圆椒

青圆椒洗净去蒂去籽，切成 **2cm 宽的菱形片**或滚刀块。蒜瓣拍扁切末，备用。

### 3. 调制酱汁

取一个小碗，按顺序加入：

- 生抽 1½汤匙
- 蚝油 1汤匙
- 料酒 1汤匙
- 白糖 ½茶匙
- 盐 ¼茶匙
- 鸡精 ¼茶匙
- 清水 3汤匙

搅拌均匀，备用。

## 烹饪步骤

### 步骤一：热锅

平底锅置于灶上，**大火加热 20 秒**。喷油壶对准锅底均匀喷洒 **6-8 次**，使锅底覆盖一层薄油。

### 步骤二：煸香蒜末

1. 转 **小火**，下入蒜末快速翻炒 **5-8 秒**。
2. 闻到蒜香、边缘微微泛黄时，立即进行下一步，避免蒜末炸糊发苦。

### 步骤三：炒青圆椒

1. 转 **大火**，下入青圆椒片，快速翻炒 **40-60 秒**。
2. 观察青椒边缘出现少许焦斑、颜色变深时即可，保持其脆嫩口感，不要炒软。

### 步骤四：下干豆腐合炒

1. 将处理好的干豆腐倒入锅中，与青圆椒一同翻炒 **30 秒**。
2. 淋入事先调好的酱汁，轻轻翻炒均匀，让每块干豆腐都沾上酱汁。
3. 转 **中火** 焖煮 **1 分钟**，使干豆腐吸饱汤汁。

### 步骤五：勾芡出锅

1. 将水淀粉搅拌均匀（防止淀粉沉淀），沿锅边淋入。
2. 转 **大火**，快速翻炒 **15-20 秒**，观察汤汁变得浓稠、能均匀挂在干豆腐和青椒表面时，立即关火。

### 步骤六：装盘

将青圆椒干豆腐盛入盘中，趁热食用口感最佳。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 干豆腐有豆腥味 | 焯水时加少许盐，焯完过凉水并挤干水分 |
| 干豆腐不入味 | 菱形块不要切太大；焖煮步骤可适当延长至 2 分钟 |
| 青圆椒太软塌 | 全程大火快炒，炒至断生即可，勾芡前保持脆嫩 |
| 喜欢辣味 | 可将其中一个青圆椒换成尖椒，或在煸蒜时加 2 个干辣椒段 |
| 想要更滑嫩 | 焯水时水中加一小撮食用碱（约 0.5g），口感会明显变软，但需多冲洗一遍 |
