## 材料清单

| 材料 | 用量 |
| :-- | :-- |
| 隔夜米饭 | 2碗（约400g） |
| 鸡蛋 | 3个 |
| 小葱 | 2根（约20g） |
| 生抽 | 1汤匙（15ml） |
| 料酒 | ½汤匙（7ml） |
| 盐 | ½茶匙（3g） |
| 白胡椒粉 | 少许 |
| 调和油 | 喷油壶计量 |
| 清水 | 1茶匙（5ml） |

---

## 准备工作

### 1. 处理米饭

将隔夜米饭从冰箱取出，用饭勺**轻轻拨散**，结块的米粒用手捏散或用勺背压开，静置回温 10 分钟备用。

### 2. 打散鸡蛋

鸡蛋打入碗中，加入：

- 料酒 ½汤匙
- 盐 ¼茶匙
- 清水 1茶匙

用筷子**充分搅打 30 秒**，至蛋液均匀、微微起泡，备用。

### 3. 切配小葱

小葱洗净，切成 **0.5cm 的葱花**。葱白和葱绿分开放置。

---

## 烹饪步骤

### 步骤一：热锅滑油

平底锅置于灶上，**大火加热 20 秒**。喷油壶对准锅底均匀喷洒 **6-8 次**，使锅底覆盖一层薄油，晃动锅身让油均匀分布。

### 步骤二：炒蛋

1. 倒入打好的蛋液，待边缘**微微凝固**时，用锅铲从外向内**轻轻推炒**。
2. 蛋液凝固 **70%** 时（仍带少许湿润），立即盛出备用。
3. 锅不用洗，保留底油。

### 步骤三：炒米饭

1. 锅中补喷 **4-6 次** 油，**大火**烧热。
2. 倒入拨散的米饭，用锅铲**背面轻轻按压**翻炒，将结块压散。
3. 持续翻炒 **2-3 分钟**，至米饭粒粒分明、在锅中**轻微跳动**。

### 步骤四：调味合炒

1. 将炒好的鸡蛋倒回锅中，与米饭**快速翻炒均匀**。
2. 淋入生抽，从锅边淋入激发酱香，快速翻炒 **30 秒**。
3. 加入剩余盐、白胡椒粉，继续翻炒 **30 秒**，至调料均匀附着。

### 步骤五：撒葱出锅

1. 撒入葱白，翻炒 **10 秒**。
2. 关火，撒入葱绿，利用余温翻拌均匀。
3. 将炒饭盛入盘中，**轻轻压实**后倒扣在另一盘中，形成漂亮的 dome 形状。

## 小贴士

| 问题 | 解决方法 |
| :-- | :-- |
| 米饭粘锅 | 确保锅够热再下米饭，冷锅下米必粘；也可先将米饭微波加热 1 分钟去水汽 |
| 米饭结块 | 下锅前务必拨散；炒时用铲背按压而非切剁，避免米粒破碎 |
| 鸡蛋太老 | 七八分熟即盛出，回锅后余温会让它刚好熟透 |
| 颜色不够金黄 | 选用土鸡蛋或增加蛋黄比例；也可在米饭中拌入 1 个生蛋黄再炒 |
| 控油需求 | 使用不粘锅可减少喷油次数；炒好后用厨房纸吸去盘底余油 |
